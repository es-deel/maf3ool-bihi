# مغامرة المفعول به — نسخة Vercel مع قاعدة بيانات

## ما في المجلد
- `public/index.html` : الدرس كاملًا (الإصدار ٩) مع طبقة «أرسل نتيجتي إلى معلمي».
- `api/submit.js` : يستقبل نتيجة الطالب (برمز الفصل) ويحفظها في قاعدة Upstash Redis.
- `api/board.js` : يعيد نتائج الفصل للمعلم فقط (بمفتاح المعلم).
- `vercel.json`, `package.json`.

## الرفع (مرة واحدة)
1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه محتويات هذا المجلد كما هي.
2. في vercel.com ← Add New ← Project ← اختر المستودع ← Deploy (بلا أي إعدادات).
3. في المشروع: Storage ← Create / Connect Database ← **Upstash Redis** (الخطة المجانية) ← Connect to Project. يضيف Vercel متغيرات البيئة تلقائيًا.
4. Settings ← Environment Variables ← أضف `TEACHER_KEY` وقيمتها كلمة سرّ تختارها (هي مفتاح المعلم) ← ثم Deployments ← Redeploy.

## الاستخدام (الأسهل: رابط الفصل)
- المعلم: «لوحتي» ← «أدوات المعلم» ← «لوحة الفصل من الإنترنت» ← اكتب رمز الفصل ← «انسخ رابط الفصل» ← أرسله لطلابك على واتساب.
- الطالب: يفتح الرابط فيرتبط بالفصل تلقائيًا؛ وتصلك نتيجته بعد كل تقدّم وعند إنهاء الرحلة بلا أي خطوة منه.

## لوحة المعلم (جديد)
«لوحتي» ← «أدوات المعلم» ← «لوحة المعلم (تحليل وتقارير)» ← رمز الفصل + مفتاح المعلم:
- تحليل شامل للفصل: المتوسطات، توزيع المستويات، أضعف/أقوى المواضيع، خريطة المواضيع لكل طالب، مجموعات الدعم والإثراء، المتوقفون، وتوصيات للحصة القادمة.
- تقرير مفصّل لكل طالب (نقاط القوة والضعف، مقارنة بالفصل، الأسئلة الخاطئة، توصيات) مع عرض وتحميل PDF وطباعة، وملخص جاهز لولي الأمر.
- تقرير الفصل PDF وجدول Excel (CSV).
- الملفات الجديدة في api: report.js (تقرير الطالب المفصّل) وتعديل submit.js وboard.js.

## الاستخدام اليدوي
- الطالب: «لوحتي» ← «أرسل نتيجتي إلى معلمي» ← يكتب رمز الفصل (مثل: خامس-أ) ← «اربط وأرسل». بعدها تُرسل نتيجته تلقائيًا كلما تقدّم.
- المعلم: «لوحتي» ← «أدوات المعلم» ← «لوحة الفصل من الإنترنت» ← رمز الفصل + مفتاح المعلم.

## ملاحظات
- يُقبل فقط «رمز النتيجة» السليم الذي يولّده الدرس نفسه (فيه توقيع تحقّق)، وحدّ الفصل الواحد ١٥٠ طالبًا.
- أي شخص يعرف رمز الفصل يستطيع إرسال نتيجة باسم طالب؛ فاختر رمزًا غير بسيط، ولوحة الفصل للمتابعة والتشجيع لا للاختبارات الرسمية.
- النسخة العادية (الصفحة المنشورة والملف المستقل) لا تتغير ولا تحتاج إنترنت.

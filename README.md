# مغامرة المفعول به — نسخة Vercel (حسابات الطلاب + قاعدة بيانات)

## كيف تعمل
- الطالب يسجّل مرة واحدة: **الاسم + الفصل (من قائمة) + رقم الهاتف**. رقم الهاتف هو كود دخوله.
- تقدّمه يُحفَظ في قاعدة البيانات تلقائيًا، وتصل نتيجته وتقريره المفصّل إلى المعلم تلقائيًا (وفورًا عند إنهاء الرحلة).
- من أي جهاز آخر: «طالب جديد» ← «لدي حساب» ← يكتب رقم هاتفه ← يستعيد تقدّمه. إن كان الرقم مسجّلًا لأكثر من طالب (إخوة) يختار اسمه.
- المعلم: زر «المعلم» ظاهر دائمًا أعلى الصفحة ← مفتاح المعلم ← لوحة فيها «يعملون الآن»، تحليل كل الفصول أو فصل واحد، تقرير كل طالب (PDF وطباعة وواتساب)، نقل الطالب بين الفصول وحذفه، و«إدارة الفصول» (قائمة الفصول التي يختار منها الطلاب؛ الافتراضي: الخامس أ، ب، ج، د).

## الملفات
- `public/index.html` : الدرس كاملًا.
- `api/config.js` (قائمة الفصول)، `join.js` (تسجيل)، `login.js` (استعادة بالهاتف)، `sync.js` (حفظ التقدّم + الإرسال + «يعمل الآن»)، `board.js` و`report.js` و`admin.js` (للمعلم فقط)، `_lib.js` (مشترك).
- **احذف `api/submit.js` من المستودع** إن كان موجودًا (قديم، لم يعد مستخدمًا).

## الرفع
1. على GitHub: Add file ← Upload files ← اسحب المجلدين `api` و`public` (يستبدلان القديم) ← Commit.
2. يعيد Vercel النشر تلقائيًا. (قاعدة Upstash ومتغيّر `TEACHER_KEY` موجودان من قبل ولا يتغيّران.)

## خصوصية وحدود
- تُخزَّن أرقام هواتف أطفال: أخبر أولياء الأمور بذلك (موافقة المدرسة) ولا تشارك لقطات شاشة فيها مفاتيح قاعدة البيانات.
- رقم الهاتف هو وسيلة الدخول الوحيدة؛ من يعرف رقم طالب واسمه يستطيع استعادة تقدّمه.
- الخطة المجانية لـ Upstash تكفي لفصول المدرسة؛ يُحفَظ التقدّم كل ١٥ ثانية من التغيير تقريبًا لا مع كل ضغطة.
- لوحة المعلم للمتابعة والتشجيع لا للاختبارات الرسمية.
